# 顺手搜索（Easy Search）

面向思源笔记 3.8.9+ 的搜索插件：

支持桌面客户端、Android/iOS/鸿蒙手机、桌面网页和手机网页；Docker 自部署通过网页使用同一安装包。

- `Ctrl/⌘+P`：用一个搜索框查笔记标题和正文。每页可选 50、100 或 200 条，默认 50，选择会保存并在插件重载后保留。结果按笔记整理：每篇笔记只占一行，显示笔记名和一条命中内容；点右侧箭头可展开这篇笔记的全部命中内容，点任一处即可跳到原文并高亮文字。翻页替换当前列表，不采用瀑布流追加。
- 全局搜索输入即查，按回车或点击“搜索”立即查找；弹窗和关键词保留，点击结果才打开笔记。
- 点击笔记标题打开整篇笔记；点击命中内容直接定位并高亮匹配文字。
- 标签达到数量上限时，关闭最早打开的未固定标签，再打开结果；结果所在笔记已经打开时直接切换并定位，保留固定标签。
- `Ctrl/⌘+Shift+F`：接管全局搜索，直接弹出搜索面板，不创建左右分栏或固定搜索页签。
- `Ctrl/⌘+F`：用 VS Code 式查找框在当前笔记逐处查找文字，打开时会带入选中文字；显示匹配序号，Enter/Shift+Enter 或 ↑ / ↓ 定位上一处/下一处并循环，全部已加载的匹配文字同时高亮。界面只显示匹配数量与上下导航；屏幕外文字加载后继续定位，正文重新渲染后恢复高亮。

上述快捷键均优先触发顺手搜索。Mac 同时支持 Control 和 Command，中文输入法组词时不接管。Ctrl/⌘+F 使用当前笔记上的独立小浮窗，只查这篇笔记；Ctrl/⌘+Shift+F 使用独立的全局搜索大弹窗。两者分别记住关键词，切换时不互相带入。未打开笔记时，Ctrl/⌘+F 提示先打开笔记。篇内浮窗关闭后继续阅读。

桌面原生搜索按钮、手机底部搜索按钮、笔记菜单和命令面板的搜索入口统一转入插件。原生搜索弹窗和页签如被其他入口唤起，会被关闭并转到插件；旧版固定搜索页签在恢复布局时自动关闭。内置替换入口隐藏，原生替换快捷键改为篇内查找；本插件不提供批量替换。设置、标签列表和大纲内的过滤、PDF 阅读器查找仍可使用。

原生搜索是思源程序的一部分，插件不删除或修改应用资源。接管随插件启用生效，禁用插件后恢复原生入口和按键。

手机没有键盘时，从思源插件菜单分别进入“顺手搜索”或“当前笔记查找”；也可以使用笔记面包屑上的查找按钮。全局搜索和篇内查找拥有独立入口。↑ / ↓ 按钮切换匹配，× 关闭篇内浮窗。手机连接键盘时也支持上述两个快捷键，全局搜索打开适合小屏的面板。

手机使用原生笔记跳转接口，不创建桌面页签；搜索面板随软键盘高度调整，按钮适合触屏。

## 代码位置

源码在 `src/`：`core.js` 是匹配和分组逻辑，`search.js` 是全局结果界面，`find.js` 是篇内查找，`index.js` 是思源插件入口，`takeover.js` 负责原生搜索入口重定向。`npm run build` 会生成思源要求的单文件 `index.js`，`npm run package` 会生成 `package.zip`。

开发需要 Node.js 22+ 和 Python 3：

```sh
npm ci
npm run check
npm test
npm run package
```

可独立克隆本仓库并运行测试；如同级目录存在子笔记索引插件源码，还会运行两款插件的集成测试。连接本机已运行的思源工作空间后，可运行 `npm run test:platforms` 检查桌面网页及手机布局。

## 安装

从 [GitHub Releases](https://github.com/rushplayer/siyuan-easy-search/releases/latest) 下载 `package.zip`，在思源「设置 → 集市 → 已下载 → 从本地安装」安装。集市收录申请合并后，也可以从思源集市安装。源码目录不要直接复制到插件目录，思源插件根目录需要直接包含 `plugin.json` 和打包后的 `index.js`。

各平台使用同一个 `package.zip`。手机使用思源内的插件安装入口；通过同步获得插件后，在该设备上确认已启用并重新加载。

## 数据与许可

搜索沿用当前思源服务器和登录会话，不依赖外部搜索服务；搜索关键词、分页偏好和最近打开列表保存在思源插件私有数据中。插件不向 GitHub 上传笔记内容。

本项目使用 [MIT 许可证](LICENSE)。

Docker：解压到所挂载思源工作空间的 `data/plugins/siyuan-easy-search/`，确保 `plugin.json` 直接位于此目录下，再在网页端启用插件并刷新。无需在 Docker 容器里安装 Node.js 或运行构建。通过反向代理访问时，插件沿用网页当前的服务器和登录会话，不连接本机桌面端。
